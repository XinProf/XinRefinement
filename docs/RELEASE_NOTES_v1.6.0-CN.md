## 主要改动

### 1. 物相显示口径三模式（默认化学式）

新增 `core/profile/naming.py`：`formula`（默认）/ `label` / `file`。

- 化学式规整只做两件安全的事：**紧凑化**（`O2 Si` → `SiO2`）与按「金属 →
  非金属 → 阴离子」**组内保序再分组**（`O4 S Zn` → `ZnSO4`、
  `Co0.1 Li1.03 Ni0.77 Co0.1 Mn0.1 O2` → `Co0.2Li1.03Ni0.77Mn0.1O2`）。
  **不改任何元素计数**，也不做电负性排序（那会打乱 NCA 这类多金属体系的熟悉
  顺序）。
- `CifStructure` 新增 `name_mineral`：`parse_cif` 按
  `_chemical_name_mineral` → `_chemical_name_common` →
  `_chemical_name_systematic` 取第一个非空。
- 三级回落（formula → label → file）保证任何 CIF 都有可显示的字串。
- **同名多型自动区分**：锐钛矿/金红石/板钛矿化学式都是 `TiO2`，日志里两个
  `TiO2.a` 就分不清谁在动 → 显示名重名时补物相名称。

### 2. 左下跑码窗口（MAUD 式滚动日志）

只读 `QPlainTextEdit`，NoWrap、最多 4000 行（长链不无限涨内存）、自动滚底，
配「清空日志」按钮。三类行：

```
=== 开始「晶胞参数」===
  参数初值：
  zero: 0.0299
  TiO2 · Anatase.a: 3.785
  ...
  TiO2 · Anatase.a: 3.785 → 3.78215
=== 「晶胞参数」done · Rwp 7.1816 → 6.9034 ===
```

- 参数行按**相对 1e-9** 过滤：浮点抖动不刷屏，真变化一定打出来。
- 首次快照没有「上一帧」可比时打印**参数初值清单**——否则日志里只剩一行
  Rwp，看不出这一轮到底在修什么。
- 晶胞按相摊平成 `TiO2 · Anatase.a` 这类键，哪一相哪根轴在动一眼可见。

### 3. 导航步骤说明窗（与跑码窗口逐条对应）

点任一 ▶ 先弹窗，然后**把同样的内容写进日志**再启动。八步各有清单：零点给
当前值、背景给模式/节点数/峰形基底、标度给每相 S、晶胞给**每相实际会精修的
分量**、峰形给 U/V/W/η/asym、xyz 给超预算策略、micro 给 X/Y/各向异性/织构、
B 给 ΔB_iso 与 6 Å² 上界。按钮文案是「▶ 开始精修」而不是「确定」。

### 4. 结果区新增两页

- **物相定量**：显示名 / wt% / e.s.d. / Z / 晶胞体积，末行给合计（QPA 理论上
  归一到 100，合计行是最快的一致性检查）。
- **晶胞与微结构**：显示名 / 精修分量 / a b c α β γ / V / 晶粒尺寸 D /
  微观应变 ε，11 列铺开。
- 各向异性相：系数是 Cholesky 3×3，界面取**奇异值均值**（体积平均）折算成
  与各向同性同量纲的 Å / ε，D 列打 `*` 标记；`aniso` 存在时不再读标量 X/Y
  （micro 步开 Popa LB 后标量已不精修，只读 X/Y 会一直显示初值）。

### 5. 修正：晶胞弹窗的勾选是装饰性的（v1.5 遗留缺陷）

- **现象**：非 a/c 复选框全部 `setEnabled(False)` 并写「全 6 参数由 P1.2
  开放」——该说法早已过期；更严重的是 `_settings["cell"]` **从来没传给引擎**，
  精修永远按晶系全放，勾选纯装饰。
- **修法**：`RefineConfig.cell_axes`（相名 → 允许分量）→ `recipe._run_cell` →
  `refine_cell_full(axes_override=...)` → `apply_cell_scales(axes=...)`。
  口径由 `resolve_axes(system, requested) = 晶系允许 ∩ 用户勾选` 统一给出，
  非法轴静默丢弃；`None`（未设置过）时与 v1.5 **逐位一致**。
- **弹窗重做**：每相一个分组框、3×2 复选框网格、两列并排（四相不再要滚 24
  行）；按晶系置灰非自由轴并给原因 tooltip（立方只放手 a；四方/六方/三方放
  a、c；单斜加 β；三斜全放）。
- 端到端：只勾 a → `3.785 → 3.78215`，c 保持 `9.5196`；配方消息由 `/ 2 参`
  改为 `/ 1 参`（原来按晶系全放开计数）。

### 6. 修正：编辑→物相参数编辑的版式

两列网格（晶胞 / 择优取向 / 织构与各向异性 / 微观应变 / 对称性两组并排）
+ `QScrollArea` + 最小宽 880：多相时底部按钮不再被挤出窗口。相选择 combo
用显示名。

## 已知限制

- **样 7 仍未达标**（+3.39 pt，方石英近非晶宽包起点问题），v1.6 未触碰引擎，
  这条留给后续专项。
- **验收判据已换口径**：立项书 §5 第 6 条改为「同数据集均值差 ≤ 1 pt 且无单
  样差 > 4 pt」，旧的逐样 `≤ MAUD+2` 降为诊断参考。
- 晶胞分量勾选只影响 `cell` 步；`profile` 步的联合精修仍按晶系全放开（它是
  另一个自由度集合，混在一起会让参数相关性诊断失真）。
