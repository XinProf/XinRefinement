## A. 事实性 / 一致性修正（必须改，低风险）

### A1. §2.1 空间群来源笔误：LFP → NCA

`PROJECT_PLAN.md` §2.1 表格写「空间群对称元数据 … 来源 `LFP core/symmetry.py`」，但实际 vendor 落地的是 **NCA 版 `core/symmetry.py`**（依赖 `data/spacegroups.json`，非 LFP 版），与 `.workbuddy/memory/2026-11-04.md` 的决策记录一致。

**建议**：把来源列改为「NCA（`data/spacegroups.json`）」，并加注"已用 NCA 版替代 LFP 版（LFP 版为独立全表，不依赖数据文件，P1 评估是否补充）"。

### A2. §3.1 架构图与当前代码树不一致

架构图画出 `core/io/`、`core/symmetry/`、`core/structure/`、`core/params/` 子包；但 P0 落地后实际是**扁平** `core/*.py`（`core/patterns.py`、`core/symmetry.py` 在 core 根，无 io/structure/params 子包）。`TASKS.md` P0.2 映射表把 patterns 写成 `core/io/patterns.py`，实际是 `core/patterns.py`。

**建议**：保留子包作为 P1 目标（io/symmetry/structure/params 是 P1 要新建的模块，分层合理），但 TASKS P0.2 映射表应标注「P1 阶段迁入 `core/io/` 子包」，并同步修正 patterns 目标路径，避免实施时来回搬文件。

### A3. spglib 集成确认为 P1.1 前置（无需改，但需强调）

当前 `core/symmetry.py` 只是 H-M→晶系/点群/劳厄群/布拉维的**元数据映射**，不是 symop 生成；spglib 尚未 import。计划 §2.2 缺口表对此描述正确。**注意依赖**：P1.2 晶胞、P1.3 坐标、P1.4 占位都依赖「Wyckoff 位识别（spglib）」，所以 P1.1 必须排在这些之前（见 C2 依赖调整）。

### A4. 界面草图交叉核对说明

本模型当前无法读取原始界面草图（`pre-temp/` 已清理删除），草图核对以计划 §6.2 的映射 + 原始需求文本为准。**建议**：留一个"界面逐条核对"的显式验收项（P3 交付时截图对照需求文本逐条打钩），避免 UI 落地后与构想脱节。

## B. 领域能力补缺（"集百家之长"尚未吃透）

### B1. 多谱（多直方图）联合精修 —— 重要缺口

GSAS-II / MAUD 的核心能力是 **XRD + 中子 / 多台仪器 / 多温度点联合拟合同一结构**（同一组结构参数同时拟合多条谱）。当前 plan 只有「序贯精修 Sequential」（逐谱依次），**没有「联合 Joint」**。两者不同。

**建议**：
- v2 待办明确新增「多谱联合精修（Joint refinement，histogram 维度）」；
- **v1 即预留**：声明式 `Parameter` 增加 `histogram` 维度（`key` 形如 `phase0.cell.a` 为跨谱共享，`phase0.scale` 为每谱独立），避免 D4 参数模型日后返工。

### B2. 仪器参数文件（IRF）+ 标样标定 —— 缺失

FullProf `.irf` / GSAS-II instrument parameter file + LaB6/Si 标样标定（零点、仪器展宽、半高宽初值）。plan D11 只说"可配置"，缺「IRF 导入 + 标样标定流程」。

**建议**：v2 新增「IRF 仪器参数文件 + 标样标定」；v1 至少支持从标样/最强峰自动估零点与展宽初值（配合 C5 自动初值）。

### B3. 各向异性峰宽（尺寸/应变）—— 缺失

Stephens 各向异性应变、Popa / 球谐各向异性尺寸、位错展宽。plan 只有各向同性 TCH X/Y。

**建议**：v2 新增「各向异性峰宽模型（Stephens / Popa / 球谐尺寸-应变）」。

### B4. 无定形 / 非晶含量（内标法）—— 缺失

加内标（刚玉 / ZnO）定无定形相与非晶含量，GSAS-II / MAUD 支持，电池材料（无定形碳 / 粘结剂）高频需求。

**建议**：v2 新增「无定形含量测定（内标法）」；与现有 Hill-Howard 定量（P2.5）分开。

### B5. 参数硬约束框架（等式/线性约束、参数耦合、多相共享）—— v2 待办缺项

plan §2.3 提到「约束 → v2 待办」，但 v2 待办表只列了「键长/键角软约束」，**缺「参数硬约束框架」**（对标 GSAS-II `mapvars`：参数等式约束、线性组合、跨相共享、固定比例）。

**建议**：v2 待办补「参数硬约束（equality/linear/coupling，对标 mapvars）」，与软约束（restraints/penalty）并列。

### B6. 消光 / 吸收校正（透射几何）—— 缺失

FullProf / GSAS-II 有消光（extinction）与透射吸收（absorption/transmission）校正。

**建议**：v2 新增「消光 + 透射吸收校正」。

### B7. TOF（飞行时间中子）边界澄清 —— 需明确

plan D11 提"中子"，但未区分**恒定波长（角度弥散）** vs **TOF**（Ikeda-Carpenter / back-to-back 指数峰形）。

**建议**：D11 澄清「v1 仅支持恒定波长（角度弥散）中子与同步辐射；TOF 数据（TOF 峰形 + TOF 参数化）归 v2」。

### B8. 权重方案 + 残差自相关统计 —— 小项

Rietveld 权重 1/σ²(Poisson) vs 1/y；Durbin-Watson（DW）统计量（FullProf 报告含）；加权残差图。

**建议**：结果区补「DW 统计量 + 权重方案选项（默认 1/σ²）」。

### B9. 数据格式清单扩展 —— 补充

除 Bruker `.raw/.ras`、GSAS 外，补：Panalytical `.xrdml/.udf`、Rigaku、MAUD `.ins/.esg`、FullProf `.dat/.pcr`、标准 `.cif` 粉谱数据。

**建议**：v2 待办的「谱图格式扩展」条目明确列出此清单。

### B10. 明确不做：ab initio 结构求解 —— 需显式排除

FullProf 有模拟退火/直接法的结构求解，但本项目定位是**精修**不是**求解**。plan §1.1 未显式排除，存在范围漂移风险。

**建议**：§1.1「不做什么」补一行「❌ ab initio 结构求解（模拟退火/直接法，归结构求解工具）」。

## C. 工程 / 任务手册优化

### C1. P1.0（声明式参数模型）重构风险最高，建议三小步落地

`ParameterRegistry` 替换硬编码 `_pack/_unpack` 触及所有精修代码，是 P1 最大风险点。一次性替换容易回归。

**建议**拆三小步，每步可验收：
- **P1.0a** 最小 `solve(inputs)->RefineResult` 串通（包一层，不重构 `_pack/_unpack`）；
- **P1.0b** `ParameterRegistry` 双轨（registry 生成 pack 顺序，与旧 `_pack` 并存逐位对比）；
- **P1.0c** 全面替换 + 旧路径删除。

### C2. 依赖调整：P1.1 spglib 提前/与 P1.0 并行

spglib 集成（P1.1）不依赖参数模型（P1.0），而 P1.2/P1.3/P1.4 依赖 Wyckoff 位识别。当前顺序 P1.0→P1.1 会让晶胞/坐标/占位卡在后面。

**建议**：调整依赖为「P1.0（主入口/参数模型）与 P1.1（spglib）可并行」，P1.2 依赖 P1.0∩P1.1。TASKS 加依赖 DAG。

### C3. 虚拟样合成器 `tools/gen_virtual.py` 需显式前置为任务卡

plan §8.2 提到它，但 P1/P2 大量验收（多晶系晶胞、位移、弯背景、PO、尺寸/应变、含量、Le Bail）都靠它合成已知真值谱。TASKS 未单列。

**建议**：在 P1 之前新增任务卡「**gen_virtual.py 参数化合成器**」：支持任意晶系/多相/零点/样品位移/背景(含弯)/PO/尺寸应变/含量/噪声/λ，seed 可复现，并冻结 golden 真值 JSON。**这是 P1/P2 验收的地基。**

### C4. NCM811 实样验证需在 P2 明确成卡

P0.3 记为"并入 P1.0 后 P2 收尾"，但 P2 表无独立实样锚点卡。

**建议**：P2 补一张「**真实数据锚点卡**」：TiO₂（RutAna）、NCM811（NCA）、LFP、NCA 实样在 `xinrefinement.core` 上跑通并登记 Rwp/含量，与家族基线对照。

### C5. 自动初值估算（易用性关键，新手"导入即出结果"的前提）

scale 初值、晶胞从 CIF、零点从标样/最强峰、背景自动估计。plan 未明确。

**建议**：P2/P3 加「**自动初值估算器**」：导入谱图+CIF 后自动给出一组可精修的初值，配合默认配方实现"一键出结果"。

### C6. XinMatch 对接接口需成任务

plan §1.2 说 core 可被 import，但未列"何时如何对接 XinMatch"。

**建议**：P4 或 v2 加「**公开库 API 契约 + XinMatch 对接 demo**」：`xinrefinement.core` 暴露稳定 `solve/quant/report` 入口 + 版本化接口约定 + 一个 XinMatch 调用示例。

### C7. TASKS 补依赖 DAG + 每卡风险注记

阶段总览有顺序，但无关键路径、无并行提示、无风险对应。

**建议**：TASKS 开头加「依赖图（关键路径 P0→P1.0/P1.1→P1.2~P1.5→P2→P3→P4）」；每张卡加「风险 / 回退」一行。

## D. 易用 / 简洁 / 高效 深化

### D1. 新手 / 专家双模式显式化

§6.3 已隐含"折叠高级参数"，建议显式化为「**新手模式（导航一键 + 默认配方）** / **专家模式（全参数树 + 全部齿轮弹窗）**」双模式切换，对标 Profex 简洁 vs GSAS-II 完备。

### D2. 参数改动即时预览

改参数 → 图谱即时重算（不重新精修），MAUD / Profex 强项。

**建议**：P3 图谱交互补「参数预览重算」；与导航式精修并存。

### D3. 精修日志 / 可复现输出

FullProf `.lst` 风格：每次精修参数变化、Rwp 历史、最终参数 + e.s.d. 文本。

**建议**：并入 P4.1 报告导出（加纯文本 `.lst` 或等价 JSON 日志），支撑 P4.3 交叉验证的可复现性。

### D4. 撤销 / 回退到任意精修步

P3.7 有"历史"，细化「回退到任意步快照」交互（保存每步参数快照，可恢复）。

### D5. 多核并行（高效性）

当前仅窗口化累加 + 峰枚举缓存。多相峰枚举 / 多起点重启 embarrassingly parallel。

**建议**：P4 性能基准后再评估，v2 加「多核并行（多相枚举/多起点）+ 可选 GPU/JIT」，避免过早优化。
