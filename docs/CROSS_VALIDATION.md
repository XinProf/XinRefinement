## 方法与局限（必读）

| 项 | 说明 |
|---|---|
| 自动化范围 | 目前仅 **GSAS-II 5.8.2**（`GSASIIscriptable`）实现脚本化对比；FullProf / MAUD / Profex 需人工导出结果文件后填表 |
| 对比量 | 晶胞 6 参数（门限 0.5%）；相分数（若参考给出） |
| GSAS-II 相分数 | `Phase fraction` 是 0–1 分数制（我们输出百分数，已在脚本内归一）。多相精修的相分数开关需在 GSAS-II GUI 的 Sample Parameters 勾选，脚本化路径未生效 → **多相 QPA 交叉验证归人工步骤** |
| Rwp/wR 不可互比 | 背景模型（Chebyshev 项数/归一化）、Kα2 处理（双线权重 vs `I(L2)/I(L1)`）、峰形参数化（Caglioti+TCH vs GSAS-II CW 剖面）均不同；本报告仅登记 |
| 复现 | `C:/gsas2main/python.exe tools/gsas2_reference.py ...` → `python tools/cross_validate.py ...`（见两脚本 docstring） |
